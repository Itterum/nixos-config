# Nixarchy Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Nixarchy the sole desktop in the `nixarchy` branch for both hosts without removing existing applications or activating the configuration.

**Architecture:** A pinned Nixarchy flake supplies one NixOS module and one Home Manager module. Focused local adapter modules enable each side through the existing shared workstation profiles, while a root-level application-selection file provides the declarative target for Nixarchy's Install menu.

**Tech Stack:** Nix flakes, NixOS modules, Home Manager, Nixarchy `v4.0.1-2`, Hyprland, SDDM

**Spec:** `docs/superpowers/specs/2026-09-01-nixarchy-migration-design.md`

## Global Constraints

- Work only on the existing `nixarchy` branch; the `cosmic` branch must remain at commit `ecdd5af`.
- Pin Nixarchy to release `v4.0.1-2`, not the moving `main` branch.
- Enable Nixarchy for both `laptop` and `desktop` through shared profiles.
- Keep Nixarchy and Hyprland binary caches enabled.
- Keep SDDM enabled and browser policy theming disabled.
- Preserve every existing application, Home Manager setting, system service, hardware module, and host-specific power setting.
- Do not run `nixos-rebuild switch` or otherwise activate the configuration.

### Task 1: Add the Nixarchy system desktop

**Files:**

- Modify: `flake.nix`
- Modify: `flake.lock` (generated by Nix)
- Create: `modules/nixos/desktop/nixarchy.nix`
- Create: `nixarchy-apps.nix`
- Modify: `profiles/nixos/workstation.nix`

**Interfaces:**

- Consumes: `inputs` passed through `nixosSystem.specialArgs` and the shared `profiles/nixos/workstation.nix` composition.
- Produces: `config.programs.nixarchy.enable = true` for both NixOS configurations and an imported root-level application selection.

- [ ] **Step 1: Verify the Nixarchy option is absent before integration**

Run:

```bash
nix eval 'path:.#nixosConfigurations.laptop.config.programs.nixarchy.enable'
```

Expected: FAIL because `programs.nixarchy` is not declared in the current configuration.

- [ ] **Step 2: Add the pinned flake input**

Add this input to `flake.nix`:

```nix
nixarchy = {
  url = "github:olafkfreund/nixarchy/v4.0.1-2";
  inputs.nixpkgs.follows = "nixpkgs";
};
```

Update only this input and its dependency graph:

```bash
nix flake update nixarchy
```

Expected: `flake.lock` gains a `nixarchy` root input locked to tag `v4.0.1-2`; unrelated existing root inputs retain their revisions.

- [ ] **Step 3: Create the empty declarative application selection**

Create `nixarchy-apps.nix` with:

```nix
{ ... }:

{
  programs.nixarchy.apps = { };
}
```

- [ ] **Step 4: Create the focused NixOS adapter module**

Create `modules/nixos/desktop/nixarchy.nix` with:

```nix
{ inputs, ... }:

{
  imports = [
    inputs.nixarchy.nixosModules.nixarchy
    ../../../nixarchy-apps.nix
  ];

  programs.nixarchy = {
    enable = true;
    user = "itterum";
    flake = "/home/itterum/nixos-config";
    displayManager = true;
    browserThemeUser = null;
    binaryCaches = true;
  };
}
```

- [ ] **Step 5: Replace only the shared COSMIC import**

In `profiles/nixos/workstation.nix`, replace:

```nix
../../modules/nixos/desktop/cosmic.nix
```

with:

```nix
../../modules/nixos/desktop/nixarchy.nix
```

Do not remove or edit any other import.

- [ ] **Step 6: Evaluate the NixOS-side result**

Run:

```bash
nix eval 'path:.#nixosConfigurations.laptop.config.programs.nixarchy.enable'
nix eval 'path:.#nixosConfigurations.desktop.config.programs.nixarchy.enable'
nix eval --raw 'path:.#nixosConfigurations.laptop.config.programs.nixarchy.user'
nix eval 'path:.#nixosConfigurations.laptop.config.services.displayManager.sddm.enable'
```

Expected output, in order: `true`, `true`, `itterum`, `true`.

- [ ] **Step 7: Commit the system integration**

```bash
git add flake.nix flake.lock nixarchy-apps.nix modules/nixos/desktop/nixarchy.nix profiles/nixos/workstation.nix
git commit -m "feat: add Nixarchy system desktop"
```
